04 / HOW IT WORKS

THE PIPELINE

NEXUS fuses computer vision with real-time 3D in a zero-dependency browser-native architecture. Built by Sarthak Mehta — no plugins needed.

01

Capture

MediaPipe accesses the webcam via WebRTC getUserMedia at up to 60fps.

02

Detect

TFLite palm detection + 21-point landmark regressor maps each hand joint in 3D space.

03

Mirror Correct

Video is CSS-flipped for natural view. Raw landmark X corrected: mirroredX = 1 − rawX.

04

Classify & Render

Gesture classifier runs on landmarks. Three.js updates 3D scene at 60fps via RAF.

11 / PROJECT DOCUMENTATION

PROJECT DOCUMENTATION

PROBLEM STATEMENT

Traditional computer interfaces rely heavily on physical input devices. NEXUS explores contactless interaction using computer vision and natural gestures, evaluated with real, repeatable tests.

OBJECTIVES
  • Implement real-time hand tracking
  • Implement face gesture recognition
  • Enable contactless 3D manipulation
  • Provide multimodal interaction (hand, face, voice, mouse, touch)
  • Demonstrate browser-based computer vision
  • Evaluate gesture recognition performance experimentally
  • Maintain privacy-conscious local processing
TECHNOLOGIES
HTML5CSS3JavaScript ES6+ Three.jsWebGLMediaPipe Hands MediaPipe Face MeshWebRTCWeb Speech API
LIMITATIONS & FUTURE SCOPE

Recognition accuracy depends on lighting and camera quality; single-hand tracking is prioritized for stability; voice control requires a Chromium-based browser. Future scope includes two-hand gestures, a trained ML gesture classifier, and WebXR support.

13 / PRIVACY & SECURITY

PRIVACY & SECURITY

LOCAL PROCESSINGYES
CAMERA PERMISSIONNOT REQUESTED
DATA STORAGESETTINGS ONLY
  • Camera access requires explicit browser permission and can be revoked at any time.
  • Video frames are processed locally in-browser via MediaPipe — nothing is uploaded to a server.
  • NEXUS has no backend; there is nowhere for footage to be sent.
  • localStorage is used only for non-sensitive UI preferences (theme, quality, toggle states) if you click Save Settings.
  • The activity log lives in memory for the current tab session and is cleared on reload unless exported manually.
